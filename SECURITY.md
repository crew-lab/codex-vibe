# Security reporting

This MIT-licensed repository contains an unpublished release candidate. Do not include credentials or personal data in reports. Use the repository's private vulnerability reporting channel if available; otherwise contact the maintainers through the repository-approved channel. Include the affected version, a minimal reproduction, and impact, with secrets removed.

Hosted inference, real-account Codex desktop registration, clean-account installation, macOS Intel, and real-hosted ACP soak remain unverified. Fake-peer ACP lifecycle tests do not establish hosted authentication or production isolation. The implementation is not an OS sandbox. See `docs/acceptance.md` before deployment.
