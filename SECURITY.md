# Security reporting

This MIT-licensed repository contains vibe-supervisor, distributed through GitHub Releases and not published to npm. Only the latest release receives fixes. Do not include credentials or personal data in reports. Use the repository's private vulnerability reporting channel if available; otherwise contact the maintainers through the repository-approved channel. Include the affected version, a minimal reproduction, and impact, with secrets removed.

The implementation is an application-level policy boundary, not an OS sandbox. What has and has not been seen on a real Vibe is in [Handoff.md](Handoff.md).
