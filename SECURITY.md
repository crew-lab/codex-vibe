# Security reporting

This MIT-licensed repository contains vibe-supervisor 2.0.0, distributed through GitHub Releases and not published to npm. Release 1.0.x continues on the `release/1.0` branch and receives security fixes only. Do not include credentials or personal data in reports. Use the repository's private vulnerability reporting channel if available; otherwise contact the maintainers through the repository-approved channel. Include the affected version, a minimal reproduction, and impact, with secrets removed.

The implementation is an application-level policy boundary, not an OS sandbox. The unverified release gates are listed in [docs/compatibility.md](docs/compatibility.md#unverified-gates); read them before deployment.
